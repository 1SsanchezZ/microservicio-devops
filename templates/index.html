Microservicio DevOps funcionando

Grupo: John Zapata y Constanza Mena

Estado del servicio: ACTIVO

Este microservicio fue desarrollado con Flask y preparado para un flujo DevOps con Docker, Docker Compose, PyTest, GitHub Actions, Dependabot y Trivy.

Herramientas DevOps utilizadas

  • Docker para contenerización.
  • Docker Compose para orquestación local.
  • PyTest para pruebas automatizadas.
  • GitHub Actions para CI/CD.
  • Dependabot y Trivy para seguridad.
